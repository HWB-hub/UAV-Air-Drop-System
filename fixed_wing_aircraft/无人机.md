## 请负责飞机的组员提供以下内容

### 1. 机体 CAD / 结构图纸(放 `cad_models/`)
- [ ] **PP(魔术)板展开图 / 激光切割文件**(DXF/PDF/SVG)。当时是网上商家代切,原图应该还有——找到后就是最有价值的文件。
- [ ] 装配说明或爆炸图(照片也行)。
- [ ] 碳纤维杆的直径/长度/布置位置说明(文字或图示)。
- [ ] 机翼、机身、尾翼关键尺寸(翼展、机长、重心 CG 位置)。报告只写了「PP板+碳纤维、载荷比 1:4」。

### 2. 飞控(放 `firmware_flight_controller/`)
- [ ] 飞控型号 + 固件版本。
- [ ] **PID 调参配置文件 / 备份**(能导出就导出;不行就截图发我)。
- [ ] 电脑端调参软件里「通道 9」接飞控的设置方法说明。
- [ ] 飞控接线的示意图。

### 3. 电路与通道映射(可放 `docs/`)
- [ ] 接收机(RF209S)到电调/舵机/飞控的完整接线表或手绘接线图。
- [ ] 确认通道表(我按报告抄的,请核对):
  | 通道 | 功能 |
  |---|---|
  | Ch1 | 副翼舵机 ×2(并联) |
  | Ch2 | 升降舵 |
  | Ch3 & Ch5 | 双电调(差速) |
  | Ch4 | 方向舵 |
  | Ch6 | **舱门 —— 投放 Rover(卫星车)** |
  | Ch9 | PID 飞控 |
- [ ] 舵机共 7 个的具体分配(副翼2+升降1+方向1+舱门1=5,剩下 2 个是什么?襟翼/翼尖/收放?)

### 4. 设备清单核对(BOM,补充缺失项)
报告里已有的:A2212 KV1400 电机、40A V2 ESC ×2、RF209S 9 通道接收机、4S 2200mAh 45C
电池、PID 飞控、PP板+碳纤维机体、舵机 ×7、螺旋桨尺寸(8040/8060/9050 三选一?请确认)。
- [ ] 遥控器具体型号(WFLY 哪款)。
- [ ] 桨、舵机具体型号、电池实际容量、总重量、续航/留空时间。

### 5. 测试与飞行数据(可放 `docs/` 或根 `data/`)
- [ ] 首飞 / 载机试飞记录(高度、时间、风速条件)。
- [ ] 投放试验记录(哪次成功、投放角度、散布、误差)。
- [ ] 如有飞控日志(黑匣子/地面站 CSV),提供一份样例。

### 6. 照片与视频(放 `media/photos/`、`media/videos/`)
- [ ] 整机照片(多角度)、舱门开合、载弹(装 Rover 卫星车)照片。
- [ ] 装配过程视频、地面滑跑/试飞视频、**真实投放并开伞回收的视频**(这是整个系统最出彩的一段)。
- [ ] 注意:单文件别超 100 MB,太大请先压缩或传到视频平台后给我链接。
